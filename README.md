# Учебная программа по шифрованию

WinForms-приложение на C# для наглядной демонстрации пяти учебных алгоритмов:

1. числовой шифр Цезаря;
2. шифр Виженера;
3. XOR;
4. RSA;
5. шифр Плейфера.

Программа имитирует взаимодействие двух участников: `Комаров-1` и
`Комаров-2`. Для каждого действия отображаются промежуточные вычисления,
выполняется обратное преобразование и проверяется восстановленный результат.

## Требования

- Windows 10 или Windows 11;
- .NET 8 SDK или более новый SDK, способный собирать `net8.0-windows`;
- подключение к NuGet при первой сборке для загрузки QuestPDF.

## Сборка и запуск

Открыть `EncryptionHomework.csproj` в Visual Studio и нажать **Запуск**.

Либо открыть PowerShell в каталоге проекта и восстановить зависимости:

```powershell
dotnet restore
```

Собрать отладочную версию:

```powershell
dotnet build .\EncryptionHomework.csproj -c Debug
```

Собрать версию Release:

```powershell
dotnet build .\EncryptionHomework.csproj -c Release
```

Запустить приложение из исходников:

```powershell
dotnet run --project .\EncryptionHomework.csproj
```

## Последовательность работы

1. Открыть вкладку нужного алгоритма.
2. Проверить или изменить исходные данные.
3. Нажать **Выполнить и создать PDF**.
4. Просмотреть вычисления и результат проверки.
5. Найти отчёт в папке `Reports` рядом с исполняемым файлом.

Вкладка **Демо** запускает все пять заранее подготовленных сценариев и создаёт
пять PDF за один раз.

Тот же демонстрационный набор можно запустить без открытия окна:

```powershell
dotnet run --project .\EncryptionHomework.csproj -- --demo
```

## Создание автономного EXE

Следующая команда создаёт один исполняемый файл для 64-разрядной Windows.
Установка .NET на компьютере пользователя для его запуска не требуется:

```powershell
dotnet publish .\EncryptionHomework.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:IncludeAllContentForSelfExtract=true -p:PublishTrimmed=false -o .\publish\win-x64
```

Готовый файл:

```text
publish\win-x64\EncryptionHomework.exe
```

Обычный запуск:

```powershell
.\publish\win-x64\EncryptionHomework.exe
```

Создание пяти демонстрационных PDF без открытия окна:

```powershell
.\publish\win-x64\EncryptionHomework.exe --demo
```

## Особенности алгоритмов

### Цезарь

Число рассматривается как последовательность десятичных цифр. Общий ключ —
одна цифра от `0` до `9`. Каждая цифра числа преобразуется отдельно по модулю
10:

```text
C = (M + K) mod 10
M = (C - K + 10) mod 10
```

Например, число `1709` с ключом `3` превращается в `4032`, а обратное
преобразование восстанавливает `1709`. Числа хранятся как строки, поэтому
начальные нули не теряются.

### Виженер

Используется русский алфавит из 33 букв, включая `Ё`. Вместо хранения квадрата
Виженера выполняются эквивалентные вычисления по модулю 33. Общая ключевая
фраза должна содержать не менее пяти букв. Пробелы во фразе разрешены и перед
вычислениями удаляются.

### XOR

Шифрование и расшифрование выполняются одной операцией:

```text
(A XOR K) XOR K = A
```

В отчёте числа показываются в десятичном и двоичном виде.

### RSA

Это учебная реализация с маленькими простыми числами. Она показывает создание
двух пар ключей, кодирование букв числами `А = 1 ... Я = 33`, шифрование
открытым ключом получателя и расшифрование его закрытым ключом.

Реализация не предназначена для защиты настоящих данных.

### Плейфер

Используется классическая английская матрица 5x5 с объединением `I/J`. У
каждого участника свой ключ. Отправитель шифрует ключом получателя, а получатель
расшифровывает тем же ключом.

При подготовке текста между одинаковыми буквами и в конце нечётного сообщения
может добавляться `X`. Поэтому результат сравнивается с подготовленным, а не с
первоначальным текстом.

## Структура

```text
Application/EncryptionScenarios.cs  сценарии двух участников и строки отчётов
Ciphers/                            реализации пяти алгоритмов
Common/RussianAlphabet.cs           единый русский алфавит
Models/                              простые классы результатов и ключей
Reporting/PdfReportService.cs       сохранение готовых строк в PDF
MainForm.cs                          интерфейс WinForms
Program.cs                           запуск приложения
```

QuestPDF используется только для оформления готовых результатов и не участвует
в криптографических вычислениях.
